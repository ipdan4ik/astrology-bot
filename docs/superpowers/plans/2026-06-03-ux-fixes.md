# UX Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix 15 UX/UI issues across the Telegram bot: FSM cancel traps, missing profile-fill CTAs, history navigation clutter, stale strings, and three new UX elements.

**Architecture:** Five independent git branches (`fix/fsm-cancel`, `fix/no-profile-cta`, `fix/history-navigation`, `fix/string-fixes`, `feat/ux-additions`), each a focused PR. Develop and merge in order 1→2→3→4→5 — later PRs branch from `main` after the previous is merged, so no rebase conflicts. Every task follows TDD: write failing test → implement → verify green → commit.

**Tech Stack:** Python 3.12, aiogram 3.x, pytest-asyncio, sqlmodel, Redis (FSM storage). Tests use a shared session-scoped PG engine; per-test isolation via TRUNCATE + Redis flush. Run tests with `pytest tests/<file>.py -x -q`.

```python
async def _daily_view(
    i18n: Translator, settings: DailySubscription | None
) -> tuple[str, InlineKeyboardMarkup]:
    enabled = settings.enabled if settings else False
    hour = settings.send_hour if settings else 9
    text = await i18n("daily.status_on", hour=hour) if enabled else await i18n("daily.status_off")
    b = InlineKeyboardBuilder()
    toggle_key = "daily.kb.turn_off" if enabled else "daily.kb.turn_on"
    b.button(text=await i18n(toggle_key), callback_data=DailyCb(action="toggle"))
    for h in range(24):
        label = f"·{h}·" if h == hour else str(h)
        b.button(text=label, callback_data=DailyCb(action="set_hour", value=h))
    b.button(text=await i18n("daily.kb.close"), callback_data=DailyCb(action="close"))
    b.adjust(1, 6, 6, 6, 6, 1)
    return text, b.as_markup()
```
