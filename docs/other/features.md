# Фичи Quantuum-бота

> Кратко, по факту кода. **Сложность реализации:** `●○○` низкая · `●●○` средняя · `●●●` высокая.

Quantuum — мультитенантная SaaS-платформа эзотерических Telegram-ботов: один **мастер-бот** заводит и обслуживает множество **клиентских ботов**, у каждого свои пользователи, оплаты и язык.

---

## 🔮 Эзотерика и разборы
*Что бот считает и генерирует.*

| Фича | Что делает | Сложность |
|---|---|:---:|
| **Натальная астрология** | Движок эфемерид (`astronomy`): позиции 10 планет + узлы, дома (Whole Sign / Porphyry) | `●●●` |
| **Нумерология** | Пифагорейская: число жизненного пути, судьбы, зрелости (+ мастер-числа 11/22/33) | `●○○` |
| **Human Design** | Бодиграф: 64 ворот, активные каналы, определённые центры | `●●○` |
| **Gene Keys** | Генные ключи поверх Human Design (тени / дары / сиддхи) | `●●○` |
| **Майянский Цолькин** | День-знак + галактический тон (260-дневный календарь, Dreamspell) | `●○○` |
| **Китайский гороскоп (Бацзы)** | Четыре столпа по лунному календарю (`lunar_python`), стихии и полярность | `●●○` |
| **Blueprint (сводный разбор)** | Композитный отчёт: 8 систем-разборов параллельно через LLM, склейка детерминированной церемониальной обёрткой (FIELD OVERVIEW + Oracle Affirmation) | `●●●` |
| **Отдельные разборы (8 систем)** | BaZi / Нумерология / Human Design / Астрология / Ведическая / Gene Keys / Майя / Аспекты — каждая отдельно полируется своим промптом, доступна по кнопке «📖 Разборы» | `●●○` |
| **Транзиты** | Текущие планеты vs натал, аспекты, отчёт за 30/60/90 дней через LLM | `●●●` |
| **Ежедневный гороскоп** | Подписка: транзит дня + LLM, рассылка в выбранный локальный час (учёт таймзоны) | `●●●` |
| **Спросить астролога (Q&A)** | Вопрос по своему профилю, ответ LLM на основе разбора | `●●○` |

## 👤 Личный кабинет и оплата
*Аккаунт пользователя, настройки, покупки.*

| Фича | Что делает | Сложность |
|---|---|:---:|
| **Онбординг и натальный профиль** | FSM сбора имени/даты/времени/места; геокодинг (Nominatim) + таймзона (`timezonefinder`) | `●●○` |
| **Профиль: просмотр и правка** | Редактирование полей, повторный геокодинг при смене места рождения | `●●○` |
| **История и скачивание** | Список прошлых блюпринтов (пагинация) и отдельных разборов, просмотр, выгрузка markdown | `●○○` |
| **Выбор языка** | Пикер языка при первом входе и в меню; запоминается per-user | `●○○` |
| **Покупки (Telegram Stars)** | `/buy` → инвойс в Stars (XTR), фулфилмент по webhook | `●●○` |

## 🛠 Управление и аналитика
*Кабинеты владельца/суперадмина, программный API, метрики.*

| Фича | Что делает | Сложность |
|---|---|:---:|
| **Кабинет владельца бота** | В мастер-боте: `/manage` — статистика, пауза/возобновление, передача владения, удаление | `●●○` |
| **Кабинет суперадмина** | В мастер-боте: `/admin` — все боты (стат/пауза/удаление) и инвайты (создание/отзыв) | `●●○` |
| **HTTP Admin API** | FastAPI: тенанты, роли, i18n-оверрайды, планы, аккаунты, статистика, аудит, платформенные эндпоинты | `●●●` |
| **Статистика и аналитика** | DAU/WAU/MAU, активные/платящие, выручка, MRR, расход LLM-токенов | `●●○` |
| **Аудит-лог** | Запись каждого изменения: актор, сущность, payload, IP/UA | `●○○` |

## 🏗 SaaS-платформа
*То, что делает продукт мультитенантным.*

| Фича | Что делает | Сложность |
|---|---|:---:|
| **Мультитенантность и автосоздание ботов** | Инвайты → онбординг владельца; бот через Bot API 9.6 (managed) или ручной токен; токены в Fernet | `●●●` |
| **Хостинг ботов (runner)** | Диспетчер на тенанта; polling и webhook; hot-reload — сверка БД с живым пулом без рестарта | `●●●` |
| **Тарифы и квоты** | Free-trial / подписки / пакеты; иерархия списания, грейс-период, напоминания о продлении | `●●●` |
| **Платежи и выплаты** | Провайдеры (Stars в проде; Cloudpayments/Cryptobot — заглушки), расчёт выплат тенанту с комиссией | `●●○` |

## ⚙️ Инфраструктура
*Техническая основа.*

| Фича | Что делает | Сложность |
|---|---|:---:|
| **Аутентификация** | Magic-link по email + JWT (+ refresh), Telegram-идентичность, суперадмин | `●●○` |
| **i18n платформы** | Базовые строки + оверрайды тенанта по языкам, Redis-кэш с инвалидацией | `●●○` |
| **Фоновые задачи (arq)** | Воркер на Redis: генерации (blueprint/qa/транзит/daily), провижининг; крон (рассылка, биллинг) | `●●○` |
| **БД и бутстрап** | 22 таблицы (SQLModel/PostgreSQL), миграции, идемпотентный бутстрап платформы | `●●○` |

---

### Внешние интеграции
Астрономический движок `astronomy` · OpenAI (LLM) · Nominatim (геокодинг) · `timezonefinder` · Telegram (aiogram) · PostgreSQL · Redis (очередь arq + FSM + кэш) · Fernet (шифрование токенов).

### Чего пока нет
Stripe / Cloudpayments / Cryptobot (только схема), синастрия / композиты / прогрессии, матрица ролей сложнее `owner|admin`.
