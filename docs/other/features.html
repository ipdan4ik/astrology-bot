Blueprint — разбор

●●●

Сводный разбор из всех систем выше, отполированный LLM. Конвейер: расчёт → LLM → доставка.

Транзиты

●●●

Текущие планеты vs натал, аспекты, отчёт за 30/60/90 дней через LLM.

Ежедневный гороскоп

●●●

Подписка: транзит дня + LLM, рассылка в выбранный локальный час (учёт таймзоны).

●●○

🏗 SaaS-платформа

то, что делает продукт мультитенантным

Мультитенантность и автосоздание ботов

●●●

Инвайты → онбординг владельца; бот через Bot API 9.6 (managed) или ручной токен; токены в Fernet.

Хостинг ботов (runner)

●●●

Диспетчер на тенанта; polling и webhook; hot-reload — сверка БД с живым пулом без рестарта.

Тарифы и квоты

●●●

Free-trial / подписки / пакеты; иерархия списания, грейс-период, напоминания о продлении.

Платежи и выплаты

●●○

Провайдеры (Stars в проде; Cloudpayments/Cryptobot — заглушки), расчёт выплат тенанту с комиссией.
